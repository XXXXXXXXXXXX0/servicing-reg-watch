# Change records

Generated by `python -m pipeline.records`: one `<doc_id>.md` per relevant document
in the review queue (BUILD_SPEC Section 8), plus `REVIEW_QUEUE.md`.

Records were generated from in-session triage (Stage A screening plus Stage B full-text reads;
see STATUS.md). Each record's Triage section gives the confidence and what was read.

A record whose `- Reviewer:` line has been filled in is never overwritten by a
later run.
